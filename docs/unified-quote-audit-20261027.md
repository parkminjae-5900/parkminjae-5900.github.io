# 다함상조·온결 계산 규칙 대조 및 개발 검증

확인일: 2026-10-27 (한국시간). 고객 홈페이지 변경·배포·main 병합 없음.

## 결론

공통 계산 엔진과 두 개발용 입력 어댑터를 별도 경로에 구현했다. 상품 방식에서는 기존 78만원을 자동 가산하지 않는다. 개별 방식은 78만원과 개별 선택을 합산하며 상품가와 혼합하지 않는다. 포함 여부를 확정하지 못한 항목은 무료가 아닌 ‘확인 필요’로 보존한다.

두 고객 화면을 교체한 작업이 아니다. 실제 화면 연결과 최종 상품구성 검증은 남아 있다.

## 기존 코드 재현 비교

고객 화면을 조작한 결과가 아니라, 실제 원본의 계산 함수를 고정 커밋에서 추출해 Node VM에서 같은 입력 조건으로 실행한 결과다. 외부비·추가품목 미입력, 빈소 미선택 조건이며 총 장례비 비교가 아니다.

기존 개별 방식에서 육수청홍수의 17만원, 오동나무 0.6관 17만원, 도우미 1인 12만원, 리무진 45만원을 선택하면 169만원이다. 새 개별 어댑터도 169만원으로 재현했다. 이는 공식 무빈소 관·수의와 사양이 완전히 같다는 의미가 아니다.

PR24에서 무빈소 120만원을 고르고 ‘기타’에 78만원을 입력하면 원본 함수는 198만원을 반환한다. 새 엔진은 120만원 소계를 유지하고 ‘기타: 분류·중복 검토 필요’로 보류한다. 이는 중복을 입력할 수 있는 경로를 재현한 것으로, 고객에게 실제 중복 청구됐다는 증거는 아니다.

새 두 어댑터를 동일 상품 모드로 실행하면 120·249·360·499만원으로 일치한다. 가상 검사용 가족장 조건(도우미 전체 3인회·포함 2인회·추가 12만원, 확인된 가상 빈소 24만원)도 두 어댑터 모두 285만원이다. 가상 조건은 실제 상품 포함 수량이나 시설가격으로 저장하지 않았다.

## 통일한 규칙

1. 상품가와 개별 필수비용은 배타적이다. 상품에서 78만원을 추가하지도 임의로 빼지도 않는다.
2. 포함 품목은 재선택해도 추가 0원으로 표시하며, 미확인 품목은 금액 null로 남긴다.
3. 인력·차량은 확인된 포함량 초과분만 계산한다. 상품 전환 시 이전 상품의 추가약정은 무효다.
4. 교체 용품은 계약으로 확인된 차액만 반영한다. 기존 판매가를 포함품목 공제금액으로 추정하지 않는다.
5. ‘기타’ 자유입력은 자동 합산하지 않는다. 인력·차량·용품 등 항목 분류와 추가 사유가 필요하다.
6. 시설·호실·현행 적용·단가·단위·과금 규칙이 확인돼야 시설비를 합산한다. 검색 최저가를 선택 호실 요금으로 대입하지 않는다.
7. 무빈소 전환 시 빈소료만 제외한다. 안치·입관실은 별도 미확인으로 유지한다.
8. 일 요금의 시간 비례·올림을 추측하지 않는다. 확인된 규칙이 없는 경우 보류한다.
9. 미확인 포함 소계를 최종 총액으로 표시하지 않는다. 개발 결과는 항상 고객용 확정 불가 상태다.
10. 내부 행사 정산 수당은 고객 견적 단가와 별개이므로 이번 계산에 섞지 않았다.
