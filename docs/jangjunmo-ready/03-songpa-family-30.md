# 송파 가족장 30명, 음식비는 조문객 수로 계산하면 될까요?

**2026년 10월 28일 기준**, 송파에서 조문객 30명 규모의 가족장을 검토할 때도 실제 음식비는 '방문 인원'과 '식사 인원·주문량'을 구분해 계산해야 합니다. 30명이 방문한다고 해서 반드시 30인분만 주문하는 것은 아니며 빈소 사용료와 상품비도 별도입니다.

장준모 운영자이자 다함상조 대표 장례지도사 박민재입니다. 송파에서는 희망 장례식장, 사용 시간, 입관·발인 일정과 조문 계획부터 정리하는 것이 좋습니다.

## 조건을 먼저 고정해 보겠습니다

- 지역: 서울 송파구
- 형태: 가족 중심 빈소 운영
- 총 조문객: 30명이라는 가정
- 실제 식사 인원: 아직 미정
- 빈소 사용 시간: 아직 미정
- 화장·장지: 미정

## 비용을 나누는 방법

| 구분 | 계산 방법 | 금액 |
|---|---|---|
| 가족장 상품 | 다함상조 대표 상품가 | 2,490,000원 |
| 빈소 | 해당 시설 사용료 × 적용 시간/일수 | 미확인 |
| 안치·입관 | 시설별 포함 여부·이용시간 확인 | 미확인 |
| 음식 | 검증된 주문 단가 × 실제 주문 수량 | 미확인 |
| 도우미 | 상품 포함 인원·근무시간 초과 여부 확인 | 미확인 |
| 화장·장지 | 관내·관외 자격·시설 선택 | 미확인 |

**확인 가능한 부분합은 가족장 대표 상품가 249만원뿐이며, 장례 전체 총액은 아직 산출할 수 없습니다.** 음식비와 상품 도우미 비용을 서로 중복 합산하지 않는 것이 중요합니다.

## 현장에서 먼저 결정할 것

1. 빈소를 2일 또는 3일 동안 운영할지
2. 가족이 직접 접객할 수 있는지, 도우미가 필요한지
3. 식사를 실제로 제공할 예상 인원과 식사 횟수
4. 희망 장례식장에서 해당 시간에 빈소 이용이 가능한지
5. 발인일에 화장 예약이 가능한지

송파권 주요 시설을 검토할 때도 시설명과 이용할 빈소를 정해야 정확한 견적이 나옵니다. 예를 들어 서울아산병원 장례식장 정보를 확인한 다음 다른 장례식장과 동일 조건으로 비교할 수 있습니다.

- 서울아산병원 장례식장 정보: https://www.dahamsangjo.co.kr/asan-funeral.html
- 가족장 구성: https://www.dahamsangjo.co.kr/family.html
- 항목별 예상견적: https://www.dahamsangjo.co.kr/funeral-cost-calculator.html

참고용 예상견적입니다. 시설 이용 조건·기간·인원·선택 항목에 따라 실제 비용이 달라질 수 있습니다. 조건을 정하셨다면 1600-6131에서 시설 가능 여부와 최종 견적을 확인하실 수 있습니다.

### 자주 묻는 질문
- **30명이면 작은 빈소만 선택하면 되나요?** 좌석·접객실·동선·가족 대기 공간까지 확인하는 것이 좋습니다.
- **음식비를 미리 확정할 수 있나요?** 실제 주문 단가와 수량이 정해지기 전에는 확정할 수 없습니다.
- **2일장이 더 저렴한가요?** 사용 시간과 화장 일정에 따라 차이가 있어 같은 조건으로 비교해야 합니다.
