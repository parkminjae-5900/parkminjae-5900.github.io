# 다함 실제장례 데이터·SEO 관제실 인수인계

기준일: 2026-10-07

## 1. 운영 목표

다함상조의 실제 장례행사 사진과 실제 영수증을 검색자산으로 전환하여 다음 흐름을 구축한다.

실제 행사자료
→ 개인정보 비식별화
→ 비용 검증
→ 사진 분류
→ 실제 장례사례 DB
→ 장례식장별 실제사례 페이지
→ 지역별 실제사례 페이지
→ 견적시스템 연결
→ SEO/GEO/AEO 노출
→ Search Console/GA4/전환 데이터 분석
→ 실제 상담·행사 전환

핵심 방향은 대량 유사문서 생산이 아니라, 실제 행사 근거가 있는 고유 데이터 축적이다.

## 2. 현재 완료된 핵심 작업

### 지역·장례식장 SEO
- 부천 휴앤유병원장례식장 전용 SEO 페이지 구축
- 인천세종병원장례식장 전용 SEO 페이지 구축
- 인천 공공데이터 기준 주요 장례식장 전체 시설별 페이지 구축
- 인천 전체 장례식장 허브 구축
- 영등포·송파·강남 핵심 장례식장 허브 구축
- 사이트맵 등록 및 내부링크 연결
- 메인페이지에서 우선 시설 허브 진입경로 추가

### SEO 검수
- conversion-funnel 검수 통과
- search-content 검수 통과
- GitHub Pages build/deploy 성공 확인

### 검색성과 데이터
Windsor.ai Search Console 연결 확인:
- https://www.dahamsangjo.co.kr/
- https://www.dahamsangjo.co.kr/jangjunmo/

초기 확인된 Google Search Console 실제 노출 예:
- 인하대병원장례식장 → inha-funeral.html
- 무빈소 가족장 → nobinso-vs-family.html
- 인천의료원장례식장 → incheon-medical-center-funeral.html

현재는 초기 색인 단계이므로, 신규 노출 → 30위권 → 20위권 → 10위권 진입 순서로 육성한다.

### 전환 추적
conversion-funnel.js에서 다음 값을 보존:
- 최초 진입 페이지
- referrer
- utm_source / medium / campaign / term / content
- 네이버 광고 n_media / n_query / n_rank / n_ad_group
- 지역
- 장례식장
- 상품
- 조문객
- 견적 클릭
- 전화 클릭
- 카카오 상담 클릭

## 4. 개인정보·공개 규칙

공개 저장소에는 원본 영수증과 원본 행사사진을 넣지 않는다.

공개 금지 기본항목:
- 고인 실명
- 상주/결제자 실명
- 전화번호
- 계좌번호
- 카드번호
- 주민등록번호
- 생년월일
- 서명
- 상세 자택주소
- QR/바코드
- 결제 식별번호
- 개인 식별 가능 정보

유족/조문객/고인 얼굴은 기본 비공개.
명시적 공개 허가 또는 안전한 비식별 처리 후에만 사용.

공개 페이지 생성 필수조건:
- publication.publish = true
- publication.privacy_reviewed = true
- publication.costs_verified = true
- 공개 사진별 privacy_checked = true

실제 행사비용은 반드시 “해당 행사 당시 실제 지출 사례”로 표기.
현재 장례식장 고정가격처럼 표현하지 않는다.

## 6. 1건의 실제 행사를 만드는 자산

한 실제 행사를 중복 doorway 페이지로 복제하지 않고 하나의 canonical 사례페이지로 운영한다.

한 사례에서 커버할 검색의도 예:
- 장례식장명 + 실제 장례비용
- 장례식장명 + 가족장
- 장례식장명 + 무빈소
- 장례식장명 + 3일장
- 장례식장명 + 30명/50명/100명 비용
- 지역 + 실제 장례비
- 지역 + 후불상조 비용
- 상품 + 실제 총비용

파생자산:
- 홈페이지 실제사례
- 장례식장 상세페이지 사례카드
- 지역페이지 사례카드
- 장준모 정보형 글
- 네이버 블로그용 현장형 콘텐츠
- 이미지 검색용 사진자료
- AI 답변용 Q&A 데이터
- 실제비용 통계 데이터

## 8. 성과 판단 규칙

노출은 많은데 클릭이 적음:
→ 제목/설명/검색의도 적합성 개선

평균순위 30~50위:
→ 고유정보·공식데이터·내부링크 강화

평균순위 10~30위:
→ 실제사례·비용근거·FAQ·사진·내부링크 집중 보강

클릭은 있는데 상담이 적음:
→ 견적 CTA·전화·카카오·사례비교 UX 개선

실제 상담/행사로 이어지는 시설·키워드:
→ 주변 파생키워드와 실제사례 데이터를 집중 확장

## 9. 자동 점검

등록된 자동점검:
- 다함 SEO 성과점검
- 우선 대상: 휴앤유, 인천세종, 인천 전역, 영등포·송파·강남
- 분석 데이터 가능 시 노출·클릭·CTR·순위·검색어·페이지·전환 확인
- 데이터 미확보 시 공개 검색결과 기반 대체 분석

## 10. 작업 재개 명령 기준

새 채팅/관제실에서 아래 문구로 재개 가능:

“다함 실제장례 데이터·SEO 관제실 인수인계 기준으로 계속 진행”

사용자가 행사사진과 영수증을 첨부하면 추가 질문을 최소화하고 본 문서의 실제 장례 데이터 엔진 절차를 즉시 적용한다.

## 11. 절대 유지사항

- 다함상조 공식 로고는 사용자 지정 원본만 사용
- 임의 로고 제작/변형 금지
- 가짜 후기/가짜 별점/가짜 행사 생성 금지
- 실제비용과 예상비용 구분
- 상품비와 외부비용 분리
- 중복 doorway 페이지 남발 금지
- 개인정보 공개 금지
- 실제 사례의 검증 가능성과 고유성을 최우선으로 유지
