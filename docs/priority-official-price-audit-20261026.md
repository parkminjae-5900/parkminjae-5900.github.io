## 수집 한계와 변경 범위

공공데이터포털 [한국장례문화진흥원 전국 장례식장 가격정보](https://www.data.go.kr/data/15021763/fileData.do)는 2023년 자료로, 현재 운영가격에 승격하지 않았다. e하늘의 시설별 페이지에서 금액 원문을 확보하지 못한 건도 검증 완료에 포함하지 않았다. 민간 블로그·검색 요약·동명이점의 가격은 근거로 채택하지 않았다.

감사대장 JSON은 전체 47개 시설의 조사 URL·상태·후속 조치와 검증 6개 시설의 가격표 텍스트 및 정규화 스냅샷을 보존한다. `suggestedSearchQuery`는 후속 검색 제안이며 수행 이력으로 해석하지 않는다. 원문 표의 병합 셀은 단위 열과 함께 대조했다.

`funeral-hall-prices.json`의 스키마 5를 유지한다. 시설목록·기존 자동수집 코드·수집 상태/보고서·견적 UI는 변경하지 않았다. PR #24의 지점 식별 개선 파일과 겹치지 않는다. 따라서 UI의 기존 이름 기반 매칭 문제를 해결했다고 주장하지 않으며, 이번 데이터는 정확한 시설명/주소로 기록했다.

## 검증

- Python unittest 전체 20개 통과(기존 15개 + 감사대장 검사 5개).
- 주소·단위·지점 URL 불일치 거부, 집계 대조, 모호 항목 제외 확인.
- 데이터 변경 전후 비교: 신규 4개, 기존 수정 2개, 나머지 37개 기록 동일.
- 배포 및 main 병합은 이 변경안에 포함하지 않는다.
- 기존 금액 범위·압축 baseline 검사, 47개 시설 범위 및 live/audit 스냅샷 일치 확인 통과.
- 브라우저 시각 검증은 Chromium 미설치 및 다운로드 실패로 수행하지 못했다. UI/이미지 파일 변경은 없다.
