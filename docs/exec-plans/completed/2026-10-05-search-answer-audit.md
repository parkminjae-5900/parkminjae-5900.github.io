# 다함상조 SEO·GEO·AEO 검수와 적용

## Goal
검색과 AI 답변에서 다함상조의 서비스·상품가·별도 비용을 정확하게 이해할 수 있도록 공개 홈페이지의 실제 안내와 검색 정보를 일치시킨다.

## Current state
- 기준 커밋: a0fecd8, GitHub Pages 정적 사이트.
- 루트 공개 페이지 79개를 검사했다. 대표주소·제목·설명·H1·로컬 파일 경로 기본 검사는 통과했다.
- 4개 페이지 FAQ 구조화데이터가 실제 질문·답변과 다르다.
- consult.html, partners.html, transfer.html이 사이트맵에 없다.
- 홈페이지 head에 문자 그대로의 역슬래시 n이 있어 head 파싱에 영향을 줄 수 있다.
- 홈페이지에 출처 없는 후기·별점과 공공데이터 검색을 협약 전체로 오해할 수 있는 표현이 있다.
- 지역 선택 스크립트가 공통 URL의 제목과 메타정보를 지역별로 덮어쓴다.
- 운영 상품은 현재 페이지와 검증 스크립트 기준 120/249/360/499만원이다. 오래된 계획/AGENTS 가격과 다르므로 이번 작업에서는 가격을 바꾸지 않는다.

## Requirements
- 기존 견적·상담·지역 선택 흐름을 유지한다.
- 질문 답변과 구조화데이터를 같은 공개 문구로 맞춘다.
- 핵심 안내를 정적 HTML로 제공하고 상품가와 외부 비용을 구분한다.
- 대표주소의 제목·설명을 지역 선택과 무관하게 유지한다.
- 상호·연락처·페이지 관계를 실제 정보로 연결한다.
- 자료 조사의 비용 투명성, 비교 질문, 사전 상담 준비 패턴을 다함상조 확인 정보에 맞게 새로 작성한다.

## Non-goals
- 상품 가격·계산 규칙·공식 로고 변경.
- 확인되지 않은 시설비·서비스·파트너·실적·리뷰 생성.
- 지역명만 바꾼 페이지 대량 생성과 순위·AI 인용 보장.

3. FAQ 동기화, 핵심 페이지 관계, 대표자 식별자와 탐색 경로를 보강한다.

5. 정적 검사와 브라우저 회귀 검수를 진행한다.
6. PR로 변경을 기록하고 배포 후 공개 페이지를 확인한다.

- llms.txt는 기존 내용을 유지하며 Google 순위 개선 수단으로 취급하지 않는다.
