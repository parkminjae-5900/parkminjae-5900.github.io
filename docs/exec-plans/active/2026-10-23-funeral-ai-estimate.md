# 전국 시설 데이터 연동 장례비 비교·견적

## Goal
기존 전국 장례식장·시설비 데이터에 연결된 대화형 비교 및 예상 견적 시제품을 별도 화면에 제공한다.

## Current state
`data/funeral-halls.json`은 전국 1,080개 시설을 담고 있으며, `data/funeral-hall-prices.json`은 공식·2차 확인 가격을 담는다. `funeral-hall-cost.html`은 시설비를 조회한다. 기존 고객용 설문에는 휴대전화 소유 인증이 없다.

## Requirements
- 지역과 시설명 질의를 처리하고 둘 이상의 시설을 비교할 수 있어야 한다.
- 상품 가격과 외부 시설비를 분리하며, 확인된 단위와 기간으로만 계산한다.
- 정보 출처와 확인일을 표시하고 과거 가격은 현재 확정가처럼 계산하지 않는다.
- 번호 대조와 SMS 인증은 서버의 검증된 인증 수단 없이는 통과시키거나 흉내 내지 않는다.

## Non-goals
- 기존 상담·정산·자료 수집 기능 변경
- 고객 개인정보의 브라우저 저장 또는 공개 자료 업로드
- 외부 SMS 인증과 실제 본인 확인이 없는 공개 접수

## Implementation steps
1. 기존 가격 항목과 시설명 연결 구조를 검사한다.
2. 별도 비교·견적 화면을 만든다.
3. 기존 시설 조회 화면에서 새 화면으로 연결한다.
4. 브라우저 및 계산 테스트를 수행한다.

## Verification plan
- 데이터 읽기·이름 매칭·단위 산정과 미확인 가격 처리 테스트
- 데스크톱·모바일 폭, 이미지·콘솔·링크 확인
- 기존 시설 조회와 다른 페이지 회귀 확인

## Risks
2023년 기준값을 2026년 확정 가격으로 오인할 위험, 시설명 중복 매칭, 화장료 지역 자격에 따른 차이, 인증되지 않은 번호로 인한 오차단.
