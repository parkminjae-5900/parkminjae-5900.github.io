# 다함상조 시군구 → 읍면동 SEO 생성 구조

## 목적
시·군·구에서 끝내지 않고 읍·면·동까지 세분화하되, 동명만 바꾼 대량 복제 페이지는 만들지 않는다.

## 기준 데이터
- 법정동: 행정표준코드관리시스템의 **현존 법정동 전체자료**
- 장례식장: 다함상조 장례식장 DB / 공공 장사시설 데이터
- 가격: 공식 공개가격 또는 현장 검증가격
- 견적: 다함상조/장준모 견적 DB 중 검증된 사례

## 생성 계층
시도 → 시군구 → 읍면동 → 장례식장 → 무빈소/가족장/일반장 → 비용/견적

## 색인 규칙
고유 신호 3개 이상만 index:
1. 해당 동 또는 인접권 장례식장
2. 검증 가격
3. 화장시설/이동권역
4. 검증 견적
5. 지역 고유 FAQ

미달 페이지는 생성되더라도 noindex,follow. 데이터가 쌓이면 자동으로 index 전환한다.

## 실행
1. `data/legal-dong.csv` 에 행정표준코드 현존 법정동 자료 저장
2. `data/funeral-halls.csv` 연결
3. 선택적으로 `data/estimate-cases.csv` 연결
4. `python tools/build-local-seo.py`
5. 검수 후 index 가능 페이지만 sitemap에 반영

## 중요
2026년 인천 등 행정구역 개편 지역은 과거 구/동 명칭으로 신규 URL을 생성하지 않는다. 법정동 현존 코드를 소스 오브 트루스로 사용한다.
